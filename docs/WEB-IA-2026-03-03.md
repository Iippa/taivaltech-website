# WEB-IA-2026-03-03

## Objective
Expand taival.tech from a single landing page into a small, navigable site that communicates:
- the practical "10x engineer" angle
- first-person founder/operator voice
- clear service entry points
- portfolio credibility
- ongoing thinking via blog

## Information Architecture

### 1) Home (`/`)
Primary conversion + narrative hub.

Sections:
1. Hero (video + image fallback)
2. 10x Engineer explanation
3. Execution model (scroll-progress section)
4. Story
5. Portfolio snapshot
6. Services snapshot
7. Blog teaser
8. About
9. Contact (Formspree)

### 2) Services (`/services/`)
Service selection page linking to detail pages:
- `/services/mechanical-design-review.html`
- `/services/prototyping-testing.html`
- `/services/npi-first-production.html`

### 3) Portfolio (`/portfolio/`)
Representative, anonymized case snapshots.

### 4) Blog (`/blog/`)
Blog index + first article:
- `/blog/odoo-integration-10x-engineer.html`

## Global Navigation
IXI-inspired minimal top navigation:
- Story
- Portfolio
- Services
- Blog
- Contact
- CTA: Get in touch

Behavior:
- Transparent over hero
- Dark sticky on scroll
- Shared across all pages

## Motion & Visual System
- Shared CSS/JS in `assets/site.css` and `assets/site.js`
- Scroll reveal animations (IntersectionObserver)
- Hero motion via `assets/hero-loop.mp4` + image fallback
- Scroll-progress indicator in execution section

## Content Strategy
- Voice: first-person Iiro, direct and technical
- No fake metrics
- No anonymous buzzword claims
- Focus on decision quality, bottleneck removal, and production reality

## Notes
- Contact flow remains Formspree on homepage.
- Umami analytics script remains on homepage.
- Design language follows dark, restrained IXI-style direction with generous spacing.
